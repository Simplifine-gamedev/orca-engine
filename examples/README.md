# Orca Engine Examples

This directory contains example projects demonstrating features and best practices for game development with Orca Engine.

## Available Examples

### RTS Demo (`rts_demo/`)
**Watchtower Vision Indicator System**

Demonstrates how to implement visual indicators for strategic points in RTS games:
- Eye icon above watchtowers to indicate vision capability
- Vision radius preview on hover
- Informative tooltips
- Team-based color coding
- RTS-style camera controls

**Related**: Linear issue [ORC-176] - Add eye icon on watchtowers to indicate vision

[View RTS Demo README](rts_demo/README.md)

## Running Examples

1. Open Orca Engine editor
2. File → Open Project
3. Navigate to `examples/<example_name>/`
4. Select `project.godot`
5. Click "Open & Edit"

## Contributing Examples

When adding new examples:
- Create a new subdirectory under `examples/`
- Include a complete Godot project with `project.godot`
- Add comprehensive README.md explaining the feature
- Document all controls and interactions
- Keep dependencies minimal
- Add comments to scripts for learning purposes
