# 3D Building Models

This directory contains 3D models for buildings in GLB/GLTF format.

## Required Models

Add 3D models for:

- headquarters.glb
- barracks.glb
- blacksmith.glb (HIGH PRIORITY)
- archery_range.glb
- stable.glb
- farm.glb
- mine.glb
- lumbermill.glb

## Model Requirements

- Format: GLB (preferred) or GLTF
- Poly count: 1,000-5,000 triangles per building
- Scale: 1 unit = 1 meter
- Textures: Embedded or in same directory
- Pivot: Bottom center of building

Until models are added, the game will display placeholder box geometries.
