# Building Thumbnails

This directory contains preview thumbnails for all buildings in the RTS game.

## Current Assets

- `blacksmith.svg` - Blacksmith building preview (placeholder)

## Required Assets

To replace placeholder assets with final artwork, add PNG or SVG files for:

- headquarters.png
- barracks.png
- archery_range.png
- stable.png
- farm.png
- mine.png
- lumbermill.png

Recommended dimensions: 128x128px or 256x256px
