# Orca RTS Game

A real-time strategy game built with React and TypeScript.

## Features

- Floating damage numbers when units attack
- Different colors for different damage types
- Toggle damage numbers on/off
- Modern React with TypeScript and Zustand for state management

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
  ├── components/     # React components
  ├── effects/        # Visual effects (damage numbers, etc.)
  ├── store/          # Zustand state management
  ├── types/          # TypeScript type definitions
  ├── App.tsx         # Main app component
  └── main.tsx        # Entry point
```
