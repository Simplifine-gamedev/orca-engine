# Orca RTS

A real-time strategy game with intuitive unit selection and control.

## Features

- **Visual Feedback**: Clear selection indicators with colored borders and health bars
- **Move vs Attack Indicators**: Visual cues for different action types
- **Control Groups**: Save unit groups with Ctrl+1-9, recall with 1-9
- **Tab Cycling**: Press Tab to cycle through selected units
- **Multi-Unit Selection**: Click and drag to select multiple units
- **Shift-Click**: Add/remove units from selection

## Controls

- **Left Click**: Select unit
- **Shift + Left Click**: Add/remove unit from selection
- **Right Click**: Move/Attack command
- **Ctrl + Number (1-9)**: Save control group
- **Number (1-9)**: Recall control group
- **Tab**: Cycle through selected units
- **Box Select**: Click and drag to select multiple units
