## Godot 4.x & GDScript 4.x Guidelines
**Always use Godot 4.x syntax and patterns:**
- Use `extends Node` (not `extends KinematicBody2D` - use `extends CharacterBody2D`)
- Use `extends RefCounted` (not `extends Reference`)
- Use `@export` for exported variables (not `export`)
- Use `@onready` for node references (not `onready`)
- Use `@tool` for editor scripts (not `tool`)
- Use typed GDScript: `var health: int = 100`, `func attack(damage: int) -> void:`
- Use `get_viewport().get_window()` for window operations
- Use `Input.get_vector()` for input handling in CharacterBody2D
- Use `move_and_slide()` without parameters in CharacterBody2D
- Use Godot 4.x signal syntax: `signal health_changed(new_health: int)`
