DESIGN PHILOSOPHY:
-----------------
The scout prioritizes EXPLORATION over COMBAT:
- Speed allows rapid map coverage and escape from threats
- Vision reveals resources, enemies, and strategic positions
- Low cost enables multiple scouts for comprehensive exploration
- Weak combat stats force strategic positioning and retreat

USAGE EXAMPLE:
-------------
import { gameStore } from './store/gameStore';

// Initialize game
gameStore.initializeGame(1);

// Create a scout
const scoutId = gameStore.createScout('player_0', { x: 100, y: 100 });

// Get scout vision
const vision = gameStore.getVisibleArea(scoutId);
console.log(`Scout can see ${vision.radius} units`); // Output: 15

// Move scout
gameStore.moveUnit(scoutId, { x: 200, y: 200 });
